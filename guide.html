サイト編集ガイド

コードが初めてでも読める。OOPartsArtsサイトの更新マニュアル。

概要・ファイル構成

このサイトは index.html という1つのファイルで動いています。編集するのは基本的にこのファイルだけです。

📁 oopartsarts/（リポジトリのルート）
📄 index.html　← メインファイル。ここを編集する
🖼 logo.png　← ロゴ画像
🎬 hero.mp4　← ヒーロー動画
📁 images/　← 作品の画像はここに入れる
🖼 work-a.jpg
🖼 work-b.jpg
…
📁 videos/　← 作品の動画はここに入れる
🎬 work-a.mp4
…
💡

画像・動画のファイル名は英数字とハイフンだけにしてください。日本語・スペース・括弧が入ると表示されないことがあります。
例: live-2024.jpg ✓   ライブ 撮影(1).jpg ✗

テキストエディタの準備

VS Code（無料） をおすすめします。インストールすると、コードに色がついて見やすくなります。

  1. code.visualstudio.com からVS Codeをダウンロード・インストール

  2. VS Codeで index.html をドラッグ＆ドロップして開く

  3. 編集したら Cmd+S（Mac）/ Ctrl+S（Windows） で保存

  4. ブラウザで index.html を開いて確認。GitHubにアップすると本番に反映される

✓

編集前に index.html を別名でコピーしておくと安心です。
例: index_backup.html

① ヒーロー動画を変える

サイトを開いたとき最初に流れる動画です。index.html を開いて、以下の1行を探してください。

<!-- HERO -->
<section class="hero">
  <video src="hero.mp4" autoplay loop muted playsinline></video>
  ...

src="hero.mp4" の hero.mp4 の部分を、使いたい動画のファイル名に変えます。

<!-- 例: live-2024.mp4 に変える場合 -->
<video src="live-2024.mp4" autoplay loop muted playsinline></video>
⚠️

動画ファイルは index.html と同じフォルダ（リポジトリのルート）に置いてください。
サブフォルダに入れた場合は src="videos/live-2024.mp4" のようにパスを書きます。

推奨動画スペック

項目推奨
形式.mp4（H.264）
解像度1920×1080 以上
ファイルサイズ30MB 以下が理想（大きいと読み込みが遅い）
長さ10〜60秒程度（ループするので短くてOK）
音声なし推奨（muted 属性で自動的にミュートされる）

② 作品を追加・編集する

index.html の下の方、<script> タグの中に const works = [...] という部分があります。ここだけ編集すれば作品が増やせます。

const works = [
  {
    gridClass: "s-wide",   // ← サイズ（後述）
    type:      "video",    // ← "image" または "video"
    title:     "ライブ撮影", // ← 作品タイトル
    tag:       "Film",     // ← カテゴリ
    year:      "2024",     // ← 年
    thumb:     "herosamune.jpg", // ← ギャラリーのサムネイル画像
    url:       "tamasi1.mp4",    // ← クリックしたとき表示するファイル
    desc:      "ライブ空間の記録。"  // ← 説明（短く）
  },
  // ↑ この {} のかたまりが1作品。, で区切って追加する
];

作品を新しく追加する手順

  1. 画像または動画ファイルを images/ または videos/ フォルダに入れる

  2. index.html を開き、const works = [ の行を探す

  3. 既存の {...}, の下に、以下のブロックをコピーして追加する

  4. ファイル名・タイトル・タグ・年・説明を書き換えて保存

{
  gridClass: "s-half",
  type:  "image",
  title: "新しい作品のタイトル",
  tag:   "Photo",
  year:  "2025",
  thumb: "images/new-work.jpg",
  url:   "images/new-work.jpg",
  desc:  "短い説明を1〜2行で。"
},
💡

thumb はギャラリー一覧に表示されるサムネイル。url は作品をクリックしたときに大きく表示されるファイルです。同じファイルを指定してOKです。

作品を削除する

削除したい作品の {...}, のブロック全体を選択して削除するだけです。

並び順を変える

works 配列の中の順番がそのままギャラリーの上から左から順番になります。ブロックの順番を入れ替えれば並び順が変わります。

サイズの種類（gridClass）

作品のサイズは gridClass で指定します。7種類あります。

s-wide
s-tall
s-full（全幅）
s-one3
s-two3
s-half
s-half
s-third
s-third
s-third
gridClass 幅 比率 使いどころ
"s-wide" 8/12列（大） 16:9 メインの横長映像・写真
"s-tall" 4/12列 4:5 縦長の写真・ポートレート
"s-full" 12/12列（全幅） 21:8（横長） インパクトのある1枚・区切り
"s-half" 6/12列（半幅） 3:2 2枚並べるとき
"s-third" 4/12列 1:1（正方形） 3枚並べるとき
"s-two3" 8/12列 3:2 s-one3 と組み合わせる
"s-one3" 4/12列 3:2 s-two3 の横に置く
✓

隣り合う作品の合計が 12列になるとき、横に並びます。ならない場合は自動で次の行に折り返します。
例: s-wide（8）+ s-tall（4）= 12 → 横並び

③ About・連絡先を変える

About テキスト

index.html の中で <!-- ABOUT --> を探してください。

<!-- ABOUT -->
<section id="about">
  <div class="reveal">
    <p class="about-name">OOPartsArts</p>       <!-- チーム名 -->
    <p class="about-location">Tokyo</p>            <!-- 拠点 -->
    <p class="about-disciplines">Film / Music / Art</p> <!-- 活動領域 -->
  </div>
  <p class="about-text reveal">
    映像・音楽・アートを制作するクリエイティブチーム。  <!-- 説明文 -->
  </p>
</section>

黄色い部分を書き換えるだけです。

連絡先

<!-- CONTACT --> の部分です。

<!-- CONTACT -->
<section id="contact">
  ...
  <div class="contact-links reveal">
    <a href="mailto:hello@example.com" class="contact-link">hello@example.com</a>
    <a href="https://instagram.com/handle" target="_blank" class="contact-link">Instagram</a>
  </div>
</section>

メールアドレスとInstagramのハンドルを自分のものに変えてください。

ファイルの置き場所

画像・動画は GitHubリポジトリの中に置きます。src="" に書くパスはリポジトリのルートからの相対パスです。

ファイルの置き場所srcに書くパス
ルート直下 work.jpg "work.jpg"
images/ フォルダの中 work.jpg "images/work.jpg"
videos/ フォルダの中 work.mp4 "videos/work.mp4"
⚠️

GitHubの無料プランはファイル1つあたり 最大100MB まで。動画はなるべく圧縮してください。
HandBrakeというアプリ（無料）を使うとMP4を小さくできます。

GitHubへのアップ方法

変更内容をサイトに反映させるには GitHubにファイルをアップロードします。

Web画面から操作する場合（簡単）

  1. GitHubのリポジトリを開く（github.com/oopartsarts/oopartsarts）

  2. index.html を更新する場合：
    index.html をクリック → 鉛筆アイコン（Edit）→ 編集 → Commit changes

  3. 画像・動画を追加する場合：
    Add file → Upload files → ファイルをドラッグ → Commit changes

  4. 1〜2分待つと https://oopartsartss-svg.github.io/oopartsarts/ に反映される

✓

反映されない場合は Ctrl+Shift+R（Cmd+Shift+R） でキャッシュをクリアしてリロードしてください。

よくある質問

Q. 画像が表示されない

以下を確認してください。

  • ファイル名に日本語・スペース・括弧が入っていないか
  • src="" のパスが正しいか（大文字小文字も区別されます）
  • ファイルがGitHubに実際にアップロードされているか

Q. 動画が再生されない（スマホ）

スマホのブラウザは autoplay 動画を muted（音なし）でないと再生しません。動画に音声が入っている場合は、動画編集ソフトで音声トラックを削除してから使ってください。

Q. 作品の順番を変えたい

const works = [...] の中のブロック（{...},）の順番を入れ替えれば、ギャラリーの順番も変わります。

Q. , （カンマ）を忘れた

各作品ブロックの末尾には , が必要です。忘れるとサイトが真っ白になります。最後の作品だけカンマなしでも動きますが、つけておく方が安全です。

  {
    gridClass: "s-half",
    ...
    desc: "説明"
  },   ← このカンマを忘れずに
  {
    ...
  }

Q. 変更したら真っ白になった

コードのどこかに書き間違いがあります。index.html を開いてVS Codeの赤いアンダーラインを探してください。バックアップを取っていた場合はそちらに戻してください。

Q. タイトルをブラウザのタブに表示させたい

index.html の一番上の <title> タグを変えます。

<title>OOPartsArts</title>

Q. サイトのURLを変えたい

GitHubのリポジトリ名がURLになります。Settings → Pages で確認できます。独自ドメインを使う場合は同じくSettings → Pages → Custom domain に入力してください。
